Formati supportati 
TESTO (una riga vuota tra una domanda e l'altra)
D: Quale metodo HTTP è idempotente?
A) POST
B) PUT
C) PATCH
Risposta: B
Spiegazione: PUT sostituisce la risorsa e ripeterlo dà lo stesso stato.

Fonte: Revisely   ← riga facoltativa: vale per tutte le domande che seguono

Varianti accettate: "Domanda:" o "12." al posto di "D:", opzioni con "a)" "A." "(A)",
"Soluzione:" o "R:" al posto di "Risposta:", spiegazione opzionale,
oppure un asterisco davanti all'opzione giusta (*B) PUT) invece della riga Risposta.
Codice nella domanda: racchiudilo tra ``` su righe separate (a capo e rientri vengono mantenuti).

JSON
[{"q":"Quale metodo HTTP è idempotente?","o":["POST","PUT","PATCH"],"a":1,"e":"Spiegazione","src":"Autovalutazione"}]
"a" può essere l'indice (0 = prima opzione) o la lettera ("B"). Nella spiegazione **testo** diventa grassetto.
Campi facoltativi: "d" = estratto delle dispense (Markdown: ##, elenchi, tabelle, ```), "ref" = riferimento ("Lezione 12, pag. 4").
Se una domanda c'è già nello stesso esame, il JSON ne aggiorna d, ref ed e (se più ricca) senza toccare id e progressi.
